# Embroidery Magic — Website

A premium, responsive showcase + custom enquiry website for **Embroidery Magic**.

## What is included

- Editorial-style landing page
- Real embroidery imagery cropped from the supplied Instagram screenshots
- Filterable portfolio
- Full-screen gallery lightbox
- Custom order / enquiry form
- WhatsApp enquiry generation
- How-it-works section
- Brand story
- Instagram CTA
- Mobile responsive layout
- No backend required for the first version

## Run locally

Open `index.html` directly, or use any static server:

```bash
npx serve .
```

## Before publishing

1. Replace the WhatsApp link in `index.html` with the business WhatsApp number.
2. Replace placeholder copy in the "Our Story" section with your sister's real story.
3. Add more original portfolio images to `assets/gallery/`.
4. Update gallery titles/categories.
5. Add a real form backend later if you want enquiries stored in a database.
6. Add Razorpay/checkout only when you want direct online payments.
